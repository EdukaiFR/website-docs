# Authentication System - Frontend Implementation 🔐

## Overview

The **Edukai Authentication System** provides a complete frontend authentication solution with secure session management, form validation, and seamless user experience. The system handles login, registration, password management, and protected routes while communicating with a Node.js backend API.

## Implementation Examples

### 🔌 **Basic Usage**

```typescript
// 1. Protect a page with AuthGuard
export default function DashboardPage() {
  return (
    <AuthGuard>
      <DashboardContent />
    </AuthGuard>
  );
}

// 2. Use authentication state
function UserProfile() {
  const { user, logout } = useSession();

  return (
    <div>
      <h1>Welcome, {user?.firstName}!</h1>
      <button onClick={logout}>Logout</button>
    </div>
  );
}

// 3. Create custom auth forms
function CustomLoginForm() {
  const { login } = useSession();

  const handleSubmit = async (credentials) => {
    const result = await login(credentials);
    if (result.success) {
      router.push("/dashboard");
    }
  };

  return <form onSubmit={handleSubmit}>...</form>;
}
```

### 🎨 **Component Integration**

```typescript
// AuthContainer with custom callbacks
<AuthContainer
  initialMode="login"
  onAuthSuccess={() => router.push('/dashboard')}
  onAuthError={(error) => showToast.error(error)}
/>

// AuthGuard with custom redirect
<AuthGuard
  redirectTo="/login"
  fallback={<CustomLoadingSpinner />}
>
  <ProtectedContent />
</AuthGuard>
```

### 🔗 **Service Integration**

```typescript
// Using auth service directly
const authService = useAuthService();

const handleLogin = async (credentials) => {
  try {
    const response = await authService.login(credentials);
    sessionStorage.setToken(response.token);
    sessionStorage.setUser(response.user);
  } catch (error) {
    console.error("Login failed:", error);
  }
};
```

## Best Practices

### ✅ **Security Best Practices**

```typescript
// Always validate tokens
const token = sessionStorage.getToken();
if (token && token !== "undefined" && token !== "null") {
  // Use validated token
}

// Clean up invalid session data
sessionStorage.cleanupInvalidData();

// Handle errors gracefully
try {
  const response = await authService.login(credentials);
} catch (error) {
  const errorMessage = translateApiError(error.response?.data?.message);
  authToast.loginError(errorMessage);
}
```

### 🎨 **Component Best Practices**

```typescript
// Use AuthGuard for protection
<AuthGuard redirectTo="/auth">
  <ProtectedComponent />
</AuthGuard>;

// Handle loading states
const { user, loading } = useSession();
if (loading) return <LoadingSpinner />;

// Use Zod for validation
const form = useForm<SigninFormValues>({
  resolver: zodResolver(signinSchema),
});
```

### ⚡ **Performance Best Practices**

- **Lazy Loading**: Load auth components on demand
- **Memoization**: Cache expensive calculations
- **Session Persistence**: Minimize API calls
- **Error Boundaries**: Prevent auth errors from crashing app

## Troubleshooting

### 🔍 **Common Issues**

1. **Session Not Persisting**: Check localStorage and token validation
2. **Redirect Loops**: Verify AuthGuard configuration and user state
3. **Form Validation Errors**: Check Zod schema definitions
4. **API Communication**: Verify environment variables and CORS settings
