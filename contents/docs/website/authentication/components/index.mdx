# Authentication Components 🎨

## Overview

The **Edukai Authentication Components** provide a complete set of UI components for user authentication, including forms, containers, guards, and pages. All components are built with React, TypeScript, and Tailwind CSS, following modern design patterns and accessibility standards.

#### **Form Rendering Logic**

```typescript
const renderAuthForm = () => {
  switch (mode) {
    case "login":
      return (
        <SigninForm
          onSuccess={handleAuthSuccess}
          onError={handleAuthError}
          onForgotPassword={() => setMode("forgot")}
        />
      );
    case "register":
      return (
        <SignupForm onSuccess={handleAuthSuccess} onError={handleAuthError} />
      );
    case "forgot":
      return (
        <ResetPasswordForm
          onSuccess={handleAuthSuccess}
          onError={handleAuthError}
          onBack={() => setMode("login")}
        />
      );
    default:
      return null;
  }
};
```

### 🛡️ **AuthGuard Component**

**File**: `components/auth/AuthGuard.tsx` (38 lines)

Protects routes and components from unauthorized access with automatic redirects.

#### **Interface & Props**

```typescript
interface AuthGuardProps {
  children: ReactNode; // Protected content
  redirectTo?: string; // Redirect URL (default: "/auth")
  fallback?: ReactNode; // Custom loading component
}

export function AuthGuard({
  children,
  redirectTo = "/auth",
  fallback,
}: AuthGuardProps) {
  const { user, loading } = useAuthGuard({ redirectTo });
  // Protection logic
}
```

#### **Protection Logic**

```typescript
export function AuthGuard({
  children,
  redirectTo = "/auth",
  fallback,
}: AuthGuardProps) {
  const { user, loading } = useAuthGuard({ redirectTo });

  // Show loading state
  if (loading) {
    return (
      fallback || (
        <div className="min-h-screen flex items-center justify-center">
          <div className="text-center">
            <div className="w-8 h-8 border-4 border-blue-500 border-t-transparent rounded-full animate-spin mx-auto mb-4"></div>
            <p className="text-gray-600">Chargement...</p>
          </div>
        </div>
      )
    );
  }

  // Redirect if not authenticated (handled by useAuthGuard)
  if (!user) {
    return null;
  }

  // Render protected content
  return <>{children}</>;
}
```

#### **Usage Examples**

```typescript
// Basic route protection
<AuthGuard>
  <DashboardPage />
</AuthGuard>

// Custom redirect and fallback
<AuthGuard
  redirectTo="/login"
  fallback={<CustomLoadingSpinner />}
>
  <ProtectedContent />
</AuthGuard>

// Page-level protection
export default function ProtectedPage() {
  return (
    <AuthGuard>
      <div>This content requires authentication</div>
    </AuthGuard>
  );
}
```

## Component Patterns

### 🎯 **Design Patterns Used**

#### **1. Container/Presenter Pattern**

```typescript
// Container manages state and logic
export function AuthContainer({ initialMode, onAuthSuccess, onAuthError }) {
  const [mode, setMode] = useState<AuthMode>(initialMode);

  const handleAuthSuccess = () => {
    console.log("Auth success for mode:", mode);
    onAuthSuccess?.();
  };

  // Renders appropriate presenter component
  return renderAuthForm();
}

// Presenter handles UI rendering
export function SigninForm({ onSuccess, onError, onForgotPassword }) {
  // Pure UI component with form handling
  return <form>...</form>;
}
```

#### **2. Compound Component Pattern**

```typescript
// AuthContainer acts as compound component
<AuthContainer initialMode="login">
  <AuthContainer.SigninForm />
  <AuthContainer.SignupForm />
  <AuthContainer.ResetPasswordForm />
  <AuthContainer.Navigation />
</AuthContainer>
```

#### **3. Render Props Pattern**

```typescript
// AuthGuard with render props
<AuthGuard>
  {({ user, loading }) =>
    loading ? <LoadingSpinner /> : <ProtectedContent user={user} />
  }
</AuthGuard>
```

#### **4. Higher-Order Component Pattern**

```typescript
// withAuth HOC for component protection
const ProtectedComponent = withAuth(MyComponent, {
  redirectTo: "/auth",
  loadingComponent: CustomLoader,
});
```
