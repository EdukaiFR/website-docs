# Project Structure

Understanding Edukai's project structure is essential for efficient development and maintenance. The project follows Next.js 13+ App Router conventions with a well-organized component hierarchy.

## 🏗️ Directory Overview

```
📁 Edukai Frontend
├── 📁 app/                       # Next.js App Router (auth & dashboard)
├── 📁 components/                # UI components (30+ ShadCN components)
├── 📁 services/                  # API service layer (4 services)
├── 📁 hooks/                     # Custom React hooks (7 hooks)
├── 📁 lib/                       # Utils, schemas, types, actions
├── 📁 contents/                  # Documentation and blog content
└── 📁 docs/frontend/             # This documentation
```

### Service Pattern

```typescript
// services/course.ts
export class CourseService {
  async createCourse(title: string, subject: string, level: string) {
    const response = await fetch('/api/courses', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ title, subject, level })
    })
    return response.json()
  }

  async getCourseById(id: string) {
    const response = await fetch(`/api/courses/${id}`)
    return response.json()
  }
}
```

## 🎯 Best Practices

1. **File Naming**: Use kebab-case for files, PascalCase for components
2. **Directory Organization**: Group by feature, then by type
3. **Import Paths**: Use absolute imports with @ prefix
4. **Component Structure**: Keep components focused and reusable
5. **Type Safety**: Define types in dedicated files
6. **Service Layer**: Abstract API calls into service classes
7. **Hook Organization**: Create custom hooks for business logic
8. **Configuration**: Centralize configuration in lib directory

This structure provides a scalable, maintainable foundation for the Edukai platform while following Next.js and React best practices.
