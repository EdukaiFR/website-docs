# Project Structure

This page provides an overview of how the Edukai frontend project is organized.

## Directory Overview

```
📁 Edukai Frontend
├── 📁 app/                       # Next.js App Router (auth & dashboard)
├── 📁 components/                # UI components (30+ ShadCN components)
├── 📁 services/                  # API service layer (4 services)
├── 📁 hooks/                     # Custom React hooks (7 hooks)
├── 📁 lib/                       # Utils, schemas, types, actions
├── 📁 contents/                  # Documentation and blog content
└── 📁 docs/frontend/             # This documentation
```
