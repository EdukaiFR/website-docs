# Frontend Documentation - Edukai Project 📚

## Overview

**Edukai Frontend** is a Next.js 14 application that provides the user interface for an AI-powered educational platform. The frontend handles quiz generation, course management, user authentication, and file processing, while communicating with a separate Node.js backend API.

## Quick Reference

### Project Tech Stack

- **Framework**: Next.js 14.2.16 with React 18
- **Language**: TypeScript with strict typing
- **Styling**: Tailwind CSS with ShadCN UI components
- **State**: Custom hooks with React state
- **API**: Axios for backend communication
- **File Processing**: Tesseract.js for OCR capabilities

### Key Directories

```
📁 Edukai Frontend
```
