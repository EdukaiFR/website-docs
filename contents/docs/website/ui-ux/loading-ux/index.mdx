# Loading UX

Edukai implements comprehensive loading states to provide excellent user experience during asynchronous operations like quiz generation, file processing, and data fetching.

## 🎯 Loading Principles

### Progressive Disclosure
- Show immediate feedback for user actions
- Provide context about what's happening
- Indicate progress when possible
- Maintain user engagement during waits

### Perceived Performance
- Use skeleton screens for predictable layouts
- Implement optimistic updates
- Show partial content as it loads
- Prioritize above-the-fold content

### Component Implementation
```tsx
// components/ui/progress.tsx
import { cn } from "@/lib/utils"

interface ProgressProps {
  value?: number
  className?: string
}

const Progress = React.forwardRef<HTMLDivElement, ProgressProps>(
  ({ className, value, ...props }, ref) => (
    <div
      ref={ref}
      className={cn(
        "relative h-4 w-full overflow-hidden rounded-full bg-secondary",
        className
      )}
      {...props}
    >
      <div
        className="h-full w-full flex-1 bg-primary transition-all"
        style={{ transform: `translateX(-${100 - (value || 0)}%)` }}
      />
    </div>
  )
)
```

### Circular Progress
```tsx
function CircularProgress({ value }: { value: number }) {
  const circumference = 2 * Math.PI * 20;
  const strokeDasharray = circumference;
  const strokeDashoffset = circumference - (value / 100) * circumference;

  return (
    <div className="relative w-12 h-12">
      <svg className="w-full h-full transform -rotate-90">
        <circle
          cx="24"
          cy="24"
          r="20"
          stroke="hsl(var(--muted))"
          strokeWidth="4"
          fill="none"
        />
        <circle
          cx="24"
          cy="24"
          r="20"
          stroke="hsl(var(--primary))"
          strokeWidth="4"
          fill="none"
          strokeDasharray={strokeDasharray}
          strokeDashoffset={strokeDashoffset}
          className="transition-all duration-300"
        />
      </svg>
      <div className="absolute inset-0 flex items-center justify-center text-xs font-medium">
        {value}%
      </div>
    </div>
  )
}
```

## 🎮 Interactive Loading States

### Quiz Generation Loading
```tsx
function QuizGenerationLoader() {
  const [stage, setStage] = useState(0)
  
  const stages = [
    "Analyzing content...",
    "Generating questions...",
    "Creating answers...",
    "Finalizing quiz..."
  ]

  useEffect(() => {
    const interval = setInterval(() => {
      setStage(prev => (prev + 1) % stages.length)
    }, 2000)
    return () => clearInterval(interval)
  }, [])

  return (
    <div className="text-center space-y-4">
      <Spinner size="lg" />
      <p className="text-muted-foreground">{stages[stage]}</p>
      <Progress value={(stage + 1) * 25} />
    </div>
  )
}
```

### File Processing States
```tsx
function FileProcessingStatus({ status }: { status: 'uploading' | 'processing' | 'complete' }) {
  const statusConfig = {
    uploading: { icon: "📤", text: "Uploading file...", color: "text-blue-500" },
    processing: { icon: "⚡", text: "Processing with OCR...", color: "text-yellow-500" },

      <span className="text-2xl">{config.icon}</span>
      <span className={cn("font-medium", config.color)}>
        {config.text}
      </span>
      {status !== 'complete' && <Spinner size="sm" />}
    </div>
  )
}
```

### Optimistic Updates
```tsx
function useOptimisticCourse() {
  const [courses, setCourses] = useState([])
  const [optimisticCourses, setOptimisticCourses] = useState([])

  const createCourse = async (courseData) => {
    // Optimistic update
    const tempCourse = { ...courseData, id: 'temp-' + Date.now(), isOptimistic: true }
    setOptimisticCourses(prev => [...prev, tempCourse])

    try {
      const newCourse = await api.createCourse(courseData)
      setCourses(prev => [...prev, newCourse])
      setOptimisticCourses(prev => prev.filter(c => c.id !== tempCourse.id))
    } catch (error) {
      setOptimisticCourses(prev => prev.filter(c => c.id !== tempCourse.id))
      throw error
    }
  }

  return {
    courses: [...courses, ...optimisticCourses],
    createCourse
  }
}
```

### Retry Mechanisms
```tsx
function useRetryableRequest(requestFn, maxRetries = 3) {
  const [state, setState] = useState({
    data: null,
    isLoading: false,
    error: null,
    retryCount: 0
  })

  const execute = async () => {
    setState(prev => ({ ...prev, isLoading: true, error: null }))
    
    try {
      const data = await requestFn()
      setState(prev => ({ ...prev, data, isLoading: false, retryCount: 0 }))
    } catch (error) {
      if (state.retryCount < maxRetries) {
        setState(prev => ({ ...prev, retryCount: prev.retryCount + 1 }))
        setTimeout(execute, 1000 * (state.retryCount + 1)) // Exponential backoff
      } else {
        setState(prev => ({ ...prev, error, isLoading: false }))
      }
    }
  }

  return { ...state, retry: execute }
}
```

## 📱 Mobile Loading Considerations

### Touch-Friendly Loading States
- Larger tap targets for retry buttons

### Network Awareness
```tsx
function NetworkAwareLoading() {
  const connection = navigator.connection
  const isSlowConnection = connection?.effectiveType === '2g' || connection?.effectiveType === '3g'

  if (isSlowConnection) {
    return (
      <div className="text-center space-y-2">
        <Spinner />
        <p className="text-sm text-muted-foreground">
          Slow connection detected. This may take a moment...
        </p>
      </div>
    )
  }

  return <Spinner />
}
```

## 🎨 Animation Guidelines

### Timing Functions
- `ease-out` for entrances
- `ease-in` for exits
- `ease-in-out` for transitions

### Duration Standards
- Micro-interactions: 100-200ms
- Component transitions: 200-300ms
- Page transitions: 300-500ms
- Loading animations: 1000ms+ (continuous)

### Reduced Motion
```css
@media (prefers-reduced-motion: reduce) {
  .animate-spin {
    animation: none;
  }
  
  .animate-pulse {
    animation: none;
    opacity: 0.5;
  }
}
```

Always respect user preferences for reduced motion to ensure accessibility.
