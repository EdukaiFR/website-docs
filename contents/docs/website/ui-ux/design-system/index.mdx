# Design System

Edukai's design system is built on **Tailwind CSS** and **ShadCN/UI** components, providing a consistent and accessible user interface across the platform.

## 🎨 Color Palette

### CSS Variables System

Our design system uses CSS variables for consistent theming and dark mode support:

```css
:root {
  --background: 220 20% 97%;
  --foreground: 240 10% 3.9%;
  --primary: 240 5.9% 10%;
  --secondary: 240 4.8% 95.9%;
  --accent: 240 4.8% 95.9%;
  --muted: 240 4.8% 95.9%;
  --destructive: 0 84.2% 60.2%;
  --border: 240 5.9% 90%;
  --ring: 240 5.9% 10%;
}
```

### Color Tokens

| Token | Light Mode | Dark Mode | Usage |
|-------|------------|-----------|--------|
| `background` | `220 20% 97%` | `240 5.9% 7.5%` | Main background |
| `foreground` | `240 10% 3.9%` | `0 0% 98%` | Primary text |
| `primary` | `240 5.9% 10%` | `0 0% 98%` | Primary actions |
| `secondary` | `240 4.8% 95.9%` | `240 3.7% 15.9%` | Secondary elements |
| `muted` | `240 4.8% 95.9%` | `240 3.7% 15.9%` | Subtle backgrounds |
| `accent` | `240 4.8% 95.9%` | `240 3.7% 15.9%` | Accent elements |
| `destructive` | `0 84.2% 60.2%` | `0 62.8% 30.6%` | Error states |

### Sidebar Colors

Special color tokens for sidebar components:

```css
--sidebar-background: 0 0% 98%;
--sidebar-foreground: 240 5.3% 26.1%;
```

## 🎯 Border Radius

Consistent border radius system:

```css
--radius: 0.5rem;

.rounded-lg: var(--radius)      /* 8px */
.rounded-md: calc(var(--radius) - 2px)  /* 6px */
.rounded-sm: calc(var(--radius) - 4px)  /* 4px */
```

## 🌙 Dark Mode

Dark mode is implemented using Tailwind's class-based approach:

```tsx
<html className={theme === 'dark' ? 'dark' : ''}>
```

All color tokens automatically switch between light and dark variants.

## 📦 Tailwind Configuration

```typescript
const config: Config = {
  darkMode: ["class"],
  theme: {
    extend: {
      fontFamily: {
        satoshi: ["Satoshi-Regular", "sans-serif"],
      },
      colors: {
        // CSS variable integration
        background: "hsl(var(--background))",
        foreground: "hsl(var(--foreground))",
        // ... other color mappings
      },
      borderRadius: {
        lg: "var(--radius)",
        md: "calc(var(--radius) - 2px)",
        sm: "calc(var(--radius) - 4px)",
      },
    },
  },
  plugins: [require("tailwindcss-animate")],
};
```

## 🔧 Customization

### Adding New Colors
1. Define CSS variable in `globals.css`
2. Add Tailwind color mapping in `tailwind.config.ts`
3. Use in components with `text-custom` or `bg-custom`

### Custom Components
Follow ShadCN/UI patterns:
- Use forwardRef for ref forwarding
- Implement variant props with class-variance-authority
- Support className prop for customization
