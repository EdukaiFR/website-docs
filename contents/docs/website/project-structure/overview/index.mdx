## Quick Reference

### Root Directory Structure

```
📁 Edukai Frontend
├── 📁 app/                       # Next.js App Router pages and layouts
├── 📁 components/                # Reusable React components
├── 📁 docs/                      # Project documentation
├── 📁 hooks/                     # Custom React hooks
├── 📁 lib/                       # Utility functions and configurations
├── 📁 services/                  # API service layer
├── 📄 package.json               # Project dependencies and scripts
├── 📄 tailwind.config.ts         # Tailwind CSS configuration
├── 📄 tsconfig.json              # TypeScript configuration
└── 📄 next.config.mjs            # Next.js configuration
```

### Key Directories

- **`app/`** - Next.js App Router with `(auth)` and `(dashboard)` route groups
- **`components/`** - UI components organized by feature with ShadCN base components
- **`services/`** - Frontend API service layer communicating with Node.js backend
- **`hooks/`** - Custom React hooks for business logic
- **`lib/`** - Utilities, schemas, types, and configurations
